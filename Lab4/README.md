# Railway station

Стационарная 3D-сцена на Python + OpenGL: один пассажирский вагон, две
платформы, здание КПП, три забора, рельсы, освещение, тени, материалы и
свободная камера. Внешних моделей и сторонних графических библиотек нет —
только PyOpenGL, GLUT/freeglut и стандартная библиотека Python. Все текстуры
процедурные, кроме официального герба Казахстана с Wikimedia Commons.

## Запуск

```bash
python3 -m pip install -r requirements.txt
# Linux, если ещё не установлен freeglut:
sudo apt install freeglut3-dev
python3 main.py
```

Для интерактивного окна нужен установленный GLUT/freeglut.

При первом запуске процедурные текстуры генерируются на CPU — это занимает
примерно 15–30 секунд. Не прерывайте процесс: после сборки откроется окно.
Сгенерированные пиксели кешируются в `.cache/textures`, поэтому повторный
запуск занимает меньше секунды. Кеш можно удалить — он создастся заново.

### Windows

```bat
py -m pip install -r requirements.txt
py main.py
```

Либо просто дважды щёлкните `run_windows.bat`. PyOpenGL для Windows содержит
DLL freeglut, поэтому отдельно устанавливать GLUT обычно не нужно. Используйте
64-битный Python. Если появляется ошибка `glutInit`, установите
Microsoft Visual C++ 2015–2022 Redistributable и переустановите PyOpenGL:

```bat
py -m pip install --force-reinstall PyOpenGL
```

## Управление: свободная камера

| Действие | Клавиша |
|---|---|
| Обзор мышью | ЛКМ или ПКМ + движение |
| Полёт вперёд / назад | `W` / `S` |
| Полёт влево / вправо | `A` / `D` |
| Полёт вверх / вниз | `E` / `Q` |
| Обзор с клавиатуры | стрелки |
| Полёт вперёд / назад | колесо мыши |
| Изменить скорость полёта | `+` / `-`, `PageUp` / `PageDown` |
| Готовые ракурсы | `1` … `9`, `0` |
| Режим разреза (скрывает ближнюю стену, стены купе и здание) | `C` |
| Включить / выключить тени | `T` |
| Автоповорот камеры | `O` |
| Сброс камеры | `R` |
| Полноэкранный режим | `F` |
| Выход | `Esc` |

Камера летает свободно: её можно поднять над станцией, облететь вагон со всех
сторон, залететь внутрь купе или вылететь за все три забора. Скорость
перемещения автоматически снижается рядом с вагоном и внутри него (примерно
4,5 м/с у платформы и 2,5 м/с в коридоре), а чувствительность мыши внутри
уменьшается. Клавиша `0` сразу переносит камеру в коридор.

Ракурсы: `1` — общий вид, `2` — вагон сбоку, `3` — разрез со всеми купе,
`4` — купе изнутри, `5` — здание КПП, `6` — туалет,
`7` — купе проводника, `8` — три забора и проезд поезда,
`9` — открытая дверь и лестница, `0` — коридор вагона.

## Что есть в сцене

* **Вагон** длиной 38,4 м (вся сцена увеличена в 1,6 раза), синий с жёлтой полосой. На обоих бортах — надпись
  `НОВОСИБИРСК-АЛМАТЫ 2` и золотой казахский солнечный герб (диск с лучами и
  орнаментом).
* **8 купе**: в каждом две нижние и две верхние полки, столик между нижними
  полками, поднятое окно, шторы, светильники над каждой верхней полкой
  и широкий дверной
  проём. Дверь сдвижная, створки уходят в карманы у стены, поэтому проход
  по центру купе не перекрывается. Полки укорочены, а увеличенный столик
  перенесён к окну, чтобы от двери был свободный проход между полками.
  По низу стен и перегородок идёт сплошной плинтус, закрывающий стык с полом.
  Окна подняты и немного уменьшены, чтобы не пересекаться с верхними полками.
* **Купе проводника**: одна нижняя полка, стол с чистым материалом, окно
  того же размера, что и в купе, потолочный светильник и открытая дверь.
* **Два туалета** в начале и в конце вагона: унитаз, раковина-чаша с
  углублением и сливом, гладкое зеркало без текстуры и отражений окон,
  светильник. Окон
  в туалетах нет, поэтому зеркало и стены больше не пересекаются.
* **Платформа** с жёлтой полосой безопасности, скамейками, урнами, фонарями и
  табличкой `ЛОКОТЬ • ПЛАТФОРМА 1`.
* **Здание КПП** из кирпича с двускатной крышей, окнами, простой прямоугольной
  дверью, флагом РФ, вывеской `КПП ЛОКОТЬ / РОССИЙСКАЯ ФЕДЕРАЦИЯ` и каменным
  цоколем по всем четырём сторонам.
* **Три вложенных забора вокруг станции** (на расстоянии 2 м друг от друга):
  сначала деревянный штакетник, за ним забор с колючей проволокой, затем обычный
  деревянный рельсовый забор. В каждом заборе с обеих сторон есть ворота-проём
  для проезда поезда.
* **Две платформы по бокам вагона**: станционная — с лавочками, фонарями,
  табличкой и зданием КПП; противоположная — простая бетонная платформа без
  мебели.
* **Открытые двери только со стороны станции**, с лестницами к платформе
  и входными тамбурами. Из тамбура — открытая дверь в туалет и проход в коридор.
* **Коридор с красной ковровой дорожкой** расширен, двери купе увеличены;
  полки укорочены, чтобы оставался проход вглубь купе. Карниза нет — только
  занавески, причём на всех окнах, включая окно купе проводника. Все окна
  одинакового размера.
* **Все двери купе, туалетов и купе проводника открыты.**
* **Надписей `ТУАЛЕТ` и `ПРОВОДНИК` на вагоне нет.**
* **Железнодорожный путь уходит за горизонт** в обе стороны — рельсы, шпалы и
  балласт продолжаются далеко за пределами станции и проходят через все три
  забора.
* Трава, много деревьев и кустов за заборами, небо с облаками и солнцем.
* Внутренние стены вагона облицованы единой текстурой, потолок и нижняя
  поверхность крыши КПП также текстурированы.

## Производительность и GPU

При запуске в терминале печатается только одна строка с управлением:

```text
Свободная камера: WASD + Q/E, мышь — обзор, 1-9/0 — ракурсы, C — разрез, T — тени, Esc — выход.
```

Если сцена сильно тормозит, скорее всего используется **программный OpenGL**
(`llvmpipe`, `softpipe` или `swrast`): видеокарта не задействована, всё
считается на CPU. Если в системе указана
NVIDIA/AMD/Intel — сцена идёт через GPU.

Что уже оптимизировано:

* карта теней статична и пересчитывается только при изменении разреза (`C`),
  а не каждый кадр;
* при выключенных тенях (`T`) шейдер вообще не читает shadow map;
* PCF уменьшен до 5 отсчётов, точечные светильники считаются без лишнего
  `pow()` на каждый источник;
* на программном рендере окно автоматически уменьшается до 960×540;
* MSAA в интерактивном окне отключён для производительности;
* В заголовке окна только название `Railway station`; FPS не считается и не выводится.

Для аппаратного ускорения нужен нормальный драйвер видеокарты. На Linux это
пакеты Mesa/проприетарный драйвер NVIDIA, на Windows — драйвер AMD/NVIDIA/Intel.
В виртуальной машине включите 3D-ускорение. Если в `Renderer` остаётся
`llvmpipe`, GPU не задействован.

## Технические детали

* OpenGL 3.3 core: VAO/VBO/EBO, GLSL-шейдеры, FBO.
* Направленный солнечный свет с картой теней 2048×2048 и PCF 3×3.
* Восемь точечных источников света внутри вагона.
* Модель освещения Блинна–Фонга: ambient/diffuse/specular, эмиссия, туман.
* Текстуры дерева, кирпича, бетона, линолеума, металла, ткани, травы, зеркала,
  потолка и неба генерируются процедурно; герб Казахстана — загруженная текстура.
* Надписи на русском нарисованы собственным векторным шрифтом с
  антиалиасингом — без PIL/FreeType.
* Герб Казахстана — растровая текстура `assets/kazakhstan_emblem_256.rgba`,
  полученная из [Emblem of Kazakhstan](https://commons.wikimedia.org/wiki/File:Emblem_of_Kazakhstan.png)
  (Wikimedia Commons).
* Собственная математика матриц/векторов; NumPy не используется.
* Свободная камера с шестью степенями свободы (полёт, мышь, WASD + Q/E).
